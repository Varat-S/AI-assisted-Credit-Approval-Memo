## Diagnosis: source → orchestration → assembly → rendering → navigation

- **Source:** the original offline sample had no Module 3 structure/management artifact.
  Its source limitations were real; a renderer could not invent those missing outputs.
  Module 2 still has governed findings rather than a standalone industry report.
- **Orchestration:** the original scripted response selected five points with text lengths
  of 51, 46, 48, 63 and 71 characters. It considered six Module 1 candidates, presenting
  five and leaving the overlapping resilience finding in audit. Sparse authored output,
  not aggressive filtering, primarily explains the thin example. No live-model compression
  behaviour was measured. The contract did not explicitly require developed evidence,
  economic mechanism and credit implication fields.
- **Assembly:** original orchestrator text equals the saved JSON text point for point.
  It did not truncate selected text. The source-to-artifact-to-HTML trace and original
  dispositions are saved in `examples/bo_corrective/diagnosis.json`.
- **Rendering:** generic recursive definition lists were used for every copied object.
  That was the wrong design for a diagram, debt schedule and refinancing timeline. The
  original renderer displayed the full short point text, but did not surface supporting
  source excerpts alongside it. It also inherited an unsuitable generic paper/card style.
- **Navigation:** exact-run resolution and consolidated loading already existed. Missing
  historical consolidated output was not explicitly explained to the reviewer. The previous
  demonstration did not prove both requested journeys through persisted application routes.

separate from drawn principal. The displayed consolidated total is the source's recorded
value, never a newly summed total. Complete creditor-priority data and qualifications are

additional events, and a vertical mobile timeline. Every original event and field is

and qualifications. No replacement conclusion is generated. Original event order is
preserved; partially dated `FY2025` records are not assigned fabricated months or resorted

existing canonical conclusion's text **before** existing evidence, numeric, qualification

No renderer-authored analysis, selection or inference is added. Old `bo-competitive-1.0`
selections remain loadable; their missing depth is not fabricated. The five-point,

Historical runs without a consolidated artifact show an explicit notice and their own
